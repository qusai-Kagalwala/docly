# Docly

Offline Windows app that makes your photos, signatures and PDFs **portal-ready** for Indian exam and government forms — plus essential PDF tools.

> In development — v1.0 MVP

## Features (v1.0)
- Portal presets (SSC, UPSC, IBPS, Passport Seva, NTA, scholarships, colleges)
- Smart crop + compress to exact KB limits
- Signature background cleaner
- PDF merge, split, reorder, images → PDF
- PDF compress to target size
- Batch mode — originals are never modified

## Privacy
100% offline. No uploads, no telemetry.

## Tech
Python · PySide6 · Pillow · OpenCV · pypdf · pikepdf

## Run from source
    python -m venv .venv
    source .venv/Scripts/activate
    pip install -r requirements.txt
    python main.py
